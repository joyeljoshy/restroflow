Recording notes: wake Render first, prepare separate staff/customer browser profiles, use a fresh idempotency key, keep one fallback prepared order, and rehearse the exact table/order so the clip does not require destructive cleanup. If live latency interrupts the sequence, pause and resume rather than claiming an edited action happened in realtime.
